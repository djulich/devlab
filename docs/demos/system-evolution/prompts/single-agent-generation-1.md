# Single-Agent Prompt — Generation 1

Develop the complete software system described by `specs/system-spec.md` and
`specs/deployment-spec.md` in this repository.

Treat both specification files as authoritative. Inspect the repository before
working, implement the product, tests, migrations, container images, Compose
stack, project-owned commands, smoke verification, and documentation required
by the specifications, and validate the result as fully as the available
operator-installed tools permit.

Work autonomously until the complete generation 1 system is ready. Do not stop
after planning or scaffolding. Do not weaken or rewrite the specifications to
match the implementation. Do not install missing host tools; report any such
verification as unverified. Keep credentials and generated runtime artifacts
out of Git. Commit the completed work with clear commit messages and leave the
working tree clean.

You do not have access to an external evaluation grader. Use only the
specifications, repository contents, and project-owned validation to judge
completion.

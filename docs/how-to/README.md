# DevLab How-to Guides

These guides provide task-oriented procedures for operating DevLab in a target
repository. For concepts, state ownership, and complete command behavior, see
the [operator guide](../operator-guide.md).

- [Adopt an existing project](adopt-existing-project.md) — establish DevLab
  planning state for a repository that already contains software.
- [Fix a bug](fix-bug.md) — describe, plan, implement, and verify a bounded bug
  fix.
- [Revise a specification](revise-specification.md) — change committed product
  requirements and reconcile the active plan.
- [Resume an interrupted workflow](resume-interrupted-workflow.md) — inspect a
  stopped run and safely continue it, including after an operator
  clarification.

Run commands from the target repository unless a guide says otherwise. DevLab
expects operator-authored changes to be committed and the Git working tree to
be clean before it starts agent sessions.
